# أداة تراخيص ERP دون اتصال

هذه أداة مستقلة لتوليد **كود تفعيل** وملف ترخيص بصيغة `.merp` لتطبيق `com.mohammedalhajsoft.integratederp`. يوقّع كل ترخيص بتوقيع **Ed25519**. لا تحتوي أداة العميل ولا حزمة APK على المفتاح الخاص.

## ضابط أمني أساسي

> احفظ المفتاح الخاص خارج مستودع المشروع وملف APK وأرشيف المصدر المرسل للعميل. استخدم مدير أسرار موثوقاً أو متغير بيئة ضمن جهاز مدير التراخيص فقط. لا ترسله عبر WhatsApp أو البريد أو ملف الترخيص.

## إنشاء زوج مفاتيح جديد

```bash
cd tools/license_generator
export PATH=/home/ubuntu/flutter/bin:$PATH
dart pub get
dart run bin/generate_keys.dart
```

ينتج الأمر متغيرين: `ERP_LICENSE_PRIVATE_KEY_BASE64` و`ERP_LICENSE_PUBLIC_KEY_BASE64`. يحتفظ مدير التراخيص بالأول فقط، بينما يضمّن الثاني في إعداد بناء تطبيق العميل. إذا استُبدل الزوج، يجب إصدار APK جديد يحتوي المفتاح العام الجديد قبل أن تقبل النسخ الجديدة التراخيص الموقعة بالمفتاح الجديد.

## إنشاء ترخيص عميل

أولاً ينسخ العميل **بصمة التثبيت** من شاشة الترخيص في التطبيق. بعد ذلك، في بيئة مدير التراخيص الآمنة:

```bash
export ERP_LICENSE_PRIVATE_KEY_BASE64='<private-key-kept-outside-project>'
export ERP_LICENSE_PUBLIC_KEY_BASE64='<matching-public-key>'
dart run bin/generate_license.dart \
  --customer "اسم العميل" \
  --installation "بصمة-التثبيت-المنسوخة" \
  --package-name "Professional" \
  --features "transactions,reports,exports" \
  --starts 2026-08-19 \
  --expires 2027-08-18 \
  --out customer-license.merp
```

لترخيص دائم، استبدل `--expires` بـ `--permanent true`. يمكن تحديد الميزات بفواصل، مثل `transactions,reports,exports`. يطبع الأمر ملف الترخيص وكود التفعيل، وكلاهما يحملان التوقيع نفسه.

## إدخال الترخيص في التطبيق

يفتح العميل **الإعدادات ← الترخيص** ثم يلصق كود التفعيل كاملاً أو يختار ملف `.merp`. يتحقق التطبيق محلياً من التوقيع والمفتاح العام ومعرّف الحزمة وبصمة التثبيت وتاريخ الصلاحية. عند فشل أي تحقق لا تُفعّل الميزات ولا تُحذف بيانات العميل، وتسجل محاولة التفعيل في سجل التدقيق المحلي.

## اختبار الأداة

تم اختبار توليد ملف يحمل الحقلين `payload_base64` و`signature_base64` بنجاح. يجب على مدير التراخيص اختبار التفعيل على نسخة تجريبية وبصمة تثبيت حقيقية قبل إرسال أول ترخيص إنتاجي.
