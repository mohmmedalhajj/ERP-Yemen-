# ملاحظات تنفيذ الإصدار 1.3.1

تم تنفيذ التعديلات داخل مصدر مشروع ERP Yemen الأصلي، مع الحفاظ على قاعدة SQLite والترقيات السابقة.

## التعديلات المنفذة

- ترقية مخطط قاعدة البيانات إلى الإصدار 7 وإضافة `purchase_currency_code` و`purchase_rate_ppm` إلى جدول `products` مع ترقية آمنة لقواعد البيانات القديمة.
- إضافة قائمة عملة الشراء وسعر الصرف إلى نموذج المنتج، وحفظهما في قاعدة البيانات، وإظهارهما في استعلامات المنتجات.
- منع خلط العملات داخل فاتورة شراء واحدة، واستخدام عملة وسعر صرف المنتج عند بدء فاتورة شراء.
- ربط إنشاء الترخيص بالعميل الموجود في قاعدة البيانات عند تطابق الاسم، وإظهار معرف العميل تلقائيًا في شاشة إنشاء الترخيص. تستخدم خدمة التراخيص توقيع Ed25519 الحقيقي والتحقق بالمفتاح العام المضمّن فقط؛ ولا يُحفظ المفتاح الخاص.
- إضافة كشوف حساب العملاء والموردين مع فلترة التاريخ والعملة، واختيار الطرف من قاعدة البيانات، وتوليد رصيد تراكمي واتجاهات مدين/دائن صحيحة للفواتير والمدفوعات.
- تمرير الفترة والعملة والطرف إلى PDF والطباعة. خدمة PDF الحالية تستخدم خطي Noto Kufi Arabic واتجاه RTL، وخدمة الطباعة الحرارية تدعم 58mm و80mm وBluetooth عبر حزم Flutter الموجودة.

## التحقق

- `flutter pub get`: ناجح.
- `flutter analyze`: ناجح دون أخطاء.
- `flutter test`: نجحت جميع الاختبارات الحالية وعددها 10.
- تعذر تنفيذ `flutter build apk --release` في بيئة التنفيذ لعدم توفر Android SDK؛ لم يكن سبب التعذر خطأً في شيفرة Dart، ويجب تشغيل البناء على جهاز أو CI يحتوي Android SDK مضبوطًا.
