# نظام المبيعات والمشتريات والإدارة المتكاملة

**المالك والمطور:** محمد الحاج سوفت — Mohammed Al-Haj Soft  
**الحزمة:** `com.mohammedalhajsoft.integratederp`  
**المنصة:** Android / Flutter 3.47.0 / Dart 3.13.0  
**نمط التشغيل:** Offline-First؛ لا يتطلب خادماً أو Firebase أو API أثناء التشغيل اليومي.

## نظرة تشغيلية

يوفر المشروع نواة ERP محلية للسوق اليمني تدعم الريال اليمني افتراضياً، وإضافة العملات وأسعار الصرف المحفوظة تاريخياً داخل المستندات. تعتمد القيم المالية على أعداد صحيحة بوحدة صغرى ولا تستخدم `double` في منطق المال. ترتبط المبيعات والمشتريات بحركة المخزون والصندوق والقيود المزدوجة ضمن معاملات SQLite واحدة.

| المجال | ما ينفذ في الإصدار | الضابط الأساسي |
|---|---|---|
| الدخول | إعداد أول، مدير محلي، تجزئة PBKDF2 مملّحة، قفل بعد محاولات فاشلة | لا تخزن كلمة مرور صريحة |
| الصلاحيات | أدوار نظام وصلاحيات منطق أعمال | لا يكتفى بإخفاء الزر |
| المنتجات | SKU وباركود ووحدة وأسعار ومخزون | أرشفة بدلاً من الحذف |
| البيع والشراء | إدخال وترحيل فعلي | فحص المخزون والائتمان والرصيد |
| المحاسبة | قيود آلية ويدوية وميزان مراجعة | منع القيد غير المتوازن أو المكرر |
| الصناديق | قبض وصرف وتحويل | حركتان متقابلتان للتحويل |
| النسخ | ملف `.merp` مشفر AES-256-GCM | Manifest وSHA-256 واستعادة بعد التحقق |
| الترخيص | تجربة محلية وملف ترخيص Ed25519 | المفتاح الخاص خارج المصدر وAPK |

## البدء

بعد تثبيت التطبيق، يعرض معالج الإعداد إنشاء المؤسسة والفرع والمخزن والصندوق وحساب المدير. ينشئ المدير المنتجات والعملاء والموردين قبل إصدار أول بيع أو شراء. يمكن فتح القائمة الجانبية من أعلى الشاشة للتنقل بين الوحدات. تدعم الإعدادات تبديل العربية والإنجليزية والوضع الفاتح والداكن والنسخ الاحتياطي والترخيص.

> لا توجد كلمة مرور افتراضية. أنشئ كلمة مرور للمدير لا تقل عن ثمانية أحرف في معالج الإعداد الأول.

## البناء والتوقيع

يحدد المشروع `minSdk` و`targetSdk` من إعداد Flutter/Android الحالي. لبناء APK تطويري:

```bash
flutter build apk --debug
```

لإنشاء مفتاح إنتاج، نفذ هذا الأمر على جهاز المالك فقط واحفظ الملف وكلمة مروره خارج Git:

```bash
keytool -genkeypair -v -keystore ~/secure/integrated-erp-release.jks \
  -alias integrated-erp -keyalg RSA -keysize 4096 -validity 10000
```

أنشئ ملف `android/key.properties` غير المتعقب:

```properties
storePassword=<set-locally>
keyPassword=<set-locally>
keyAlias=integrated-erp
storeFile=/absolute/path/integrated-erp-release.jks
```

بعد إضافة منطق قراءة `key.properties` الموثق في `release/documentation/BUILD_AND_SIGNING.md`، نفذ:

```bash
flutter build apk --release
flutter build appbundle --release
sha256sum build/app/outputs/flutter-apk/app-release.apk
```

## الترخيص Offline

لا يتضمن المستودع مفتاحاً خاصاً. يجب أن ينشئ مالك المنتج بذرة Ed25519 بطول 32 بايت، ويحفظها في مدير أسرار أو وسيط مشفر غير متصل، ثم يستدعي الأداة:

```bash
ERP_LICENSE_SEED_BASE64="<base64-seed>" dart run tools/license_generator.dart \
  --customer "اسم العميل" --customer-number "C-001" \
  --installation-id "<البصمة من شاشة الترخيص>" \
  --plan standard --max-branches 1 \
  --expires-at 2027-12-31T23:59:59Z --output client.merp
```

يبنى التطبيق الإنتاجي بالمفتاح العام المقابل فقط:

```bash
flutter build apk --release --dart-define=ERP_LICENSE_PUBLIC_KEY="<base64-public-key>"
```

عند غياب الترخيص تنطبق فترة تجريبية 14 يوماً. عند الانتهاء، تمنع طبقة منطق الأعمال العمليات الجديدة وتبقي القراءة والتقارير والنسخ متاحة. لا تدّعي آلية الوقت حماية مطلقة؛ بل تكشف رجوع الوقت الكبير وتعرض تحذيراً لا يحذف بيانات العميل.

## النسخ الاحتياطي والاستعادة

ينشئ التطبيق نسخة SQLite متسقة ثم يضمها مع Manifest داخل ZIP مشفر بـ AES-256-GCM. يحوي Manifest إصدار التطبيق وإصدار المخطط وتاريخ الإنشاء وSHA-256 لقاعدة البيانات. اختر كلمة مرور لا تقل عن 8 أحرف واحفظها منفصلة عن ملف `.merp`. عند الاستعادة يفحص التطبيق كلمة المرور وسلامة الملف وإصدار المخطط ثم يصنع نسخة أمان لقاعدة البيانات السابقة. بعد الاستعادة أغلق التطبيق وافتحه مجدداً.

## سياسات البيانات والخصوصية

يخزن التطبيق قاعدة البيانات والمرفقات ضمن مساحة التطبيق المحلية. لا ينقل التطبيق محتوى المؤسسة إلى الشبكة. تخزن كلمات المرور كتجزئة PBKDF2-HMAC-SHA256 مملّحة، وتستخدم مساحة تخزين Android الآمنة لمعرف التثبيت. لا يسجل سجل التدقيق كلمات المرور أو المفاتيح أو بيانات النسخ غير المشفرة.
